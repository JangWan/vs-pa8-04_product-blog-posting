## 1. 개요

| UC | 기능명 | 한 줄 설명 | 관련 URL |
|----|--------|---------|---------|
| UC-07 | 콘텐츠 생성 폼 | 주제·키워드·방향·지침을 입력하고 AI 초안 생성을 요청한다 | `/generate` |
| UC-08 | AI 스트리밍 생성 | AI가 스트리밍으로 초안을 생성하며 실시간으로 화면에 표시한다 | `/generate` |

## 3. 정상 흐름

### UC-07 — 콘텐츠 생성 폼

| 단계 | 행동 주체 | 내용 |
|------|---------|------|
| 1 | `User` | `/generate` 접근 (Sidebar "콘텐츠 생성" 클릭 또는 대시보드 "새 콘텐츠 생성" 클릭). |
| 2 | 시스템 | `GET /api/guidelines` 호출로 사용자의 지침 목록 조회. |
| 3 | 시스템 | 생성 폼 렌더링: |
| | | • **주제** (Textarea, 필수, 최대 300자) |
| | | • **키워드** (태그 입력, 선택, 최대 5개 — 스페이스·엔터로 태그 추가) |
| | | • **글 방향** (Textarea, 선택, 최대 200자) |
| | | • **지침 선택** (Dropdown — 지침 목록, 기본 지침 자동 선택, 없으면 "기본 SEO 지침" 선택됨) |
| 4 | `User` | 주제 입력 (필수). 키워드·방향은 선택적으로 입력. 지침 드롭다운에서 원하는 지침 선택(또는 유지). |
| 5 | `User` | "AI 초안 생성" 버튼 클릭. |
| 6 | 시스템 | 클라이언트 유효성 검사: 주제 미입력 시 인라인 에러 표시 → UC-08 진행 중단. 통과 시 UC-08 진행. |

### UC-08 — AI 스트리밍 생성

| 단계 | 행동 주체 | 내용 |
|------|---------|------|
| 1 | 시스템 | "AI 초안 생성" 버튼 비활성화 + `<Loader2>` 스피너 + "AI가 초안을 작성하고 있습니다..." 텍스트 표시. 취소 버튼 활성화. |
| 2 | 시스템 | `POST /api/generate/stream` 요청 전송: `{ topic, keywords, direction, guidelineId }`. |
| 3 | 시스템(Hono) | 선택된 지침 내용을 DB에서 조회. `buildSystemInstruction(guidelineContent)` 호출로 시스템 프롬프트 조합 (SEO 규칙 자동 포함). |
| 4 | 시스템(Gemini) | `ai.models.generateContentStream()` 호출. 스트리밍 청크 반환 시작. |
| 5 | 시스템 | 클라이언트에 `ReadableStream`으로 청크 전달. 화면에 수신된 텍스트 실시간 append. |
| 6 | 시스템 | 스트리밍 완료 감지 (`done: true`). 완성된 마크다운 본문과 `seo_meta`를 `contents` 테이블에 자동 INSERT (BR-13): `user_id`, `guideline_id`, `topic`, `keywords`, `direction`, `body`, `seo_meta`, `created_at`. |
| 7 | 시스템 | 저장 완료 후 마지막 스트리밍 청크로 `[DONE]{"id":"<contents.id>","seo_meta":{...}}` 전송. |
| 8 | 시스템 | 클라이언트가 `[DONE]` prefix 감지 → JSON 파싱 → `contents.id` 추출. |
| 9 | 시스템 | `/generate/[id]` (새 콘텐츠 ID)로 리다이렉트. "초안 생성이 완료되었습니다." 성공 토스트 표시. |

### UC-09 — 생성 결과 에디터

| 단계 | 행동 주체 | 내용 |
|------|---------|------|
| 1 | `User` | `/generate/[id]` 접근 (UC-08 리다이렉트 또는 직접 URL 입력). |
| 2 | 시스템 | `GET /api/history/:id` 호출로 콘텐츠 조회. 소유권 확인 (PC-06). |
| 3 | 시스템 | MDX Editor (`@mdxeditor/editor`) 렌더링. 생성된 마크다운 본문 로딩. 메타 정보 표시: 지침명 (삭제된 경우 "삭제된 지침") + 생성일 + 키워드 태그. |
| 4 | `User` | MDX Editor에서 초안 내용 직접 편집. |
| 5 | `User` | "저장" 버튼 클릭. |
| 6 | 시스템 | `PUT /api/history/:id` 요청: `{ body: 편집된_마크다운_전문 }`. 저장 중 버튼 비활성화 + "저장 중..." 표시. |
| 7 | 시스템 | DB UPDATE 완료. "저장되었습니다." 성공 토스트. 저장 버튼 활성화 복귀. |
| 8 | `User` | "전체 복사" 버튼 클릭. |
| 9 | 시스템 | 현재 에디터 내용을 클립보드에 복사. "클립보드에 복사되었습니다." 성공 토스트. |

- **공통 UI 패턴**: usecase-common.md §4 참조

**생성 폼 (`/generate`)**

| 요소 | 스펙 |
|------|------|
| 주제 Textarea | 최소 높이 80px, 자동 높이 확장. 우측 하단 글자 수 카운터 (`현재/300`). |
| 키워드 태그 입력 | 스페이스·쉼표·엔터로 태그 추가. 태그 삭제 X 버튼. 최대 5개 도달 시 입력 비활성화. |
| 방향 Textarea | 최소 높이 60px. 우측 하단 글자 수 카운터 (`현재/200`). |
| 지침 드롭다운 | shadcn/ui `<Select>`. 선택된 지침 기본 지침 여부 Badge 표시. |
| 생성 버튼 | Magic UI `Ripple` 효과. Sage Green Primary. 생성 중 비활성화 + 스피너. |
| 취소 버튼 | 생성 중에만 표시. Ghost 스타일. |

**스트리밍 표시 영역 (UC-08)**

| 요소 | 스펙 |
|------|------|
| 스트리밍 텍스트 | 생성 폼 하단 또는 별도 영역에 마크다운 실시간 렌더링 (react-markdown 또는 MDX Editor 미리보기). |
| 스크롤 | 텍스트 추가 시 자동 스크롤 다운. |

**에디터 (`/generate/[id]`)**

| 요소 | 스펙 |
|------|------|
| MDX Editor | `@mdxeditor/editor`. WYSIWYG + 마크다운 소스 전환 탭. |
| 메타 정보 영역 | 에디터 상단: 지침명(Badge) + 생성일 + 키워드 태그 (읽기 전용). |
| 액션 버튼 | "저장" (Lucide `<Save>`, Primary) + "전체 복사" (Lucide `<Copy>`) + "마크다운 다운로드" (Lucide `<Download>`). 에디터 우상단 위치. |

**이탈 경고 구현 (BR-17)**

편집 내용이 있고 아직 저장하지 않은 상태에서 페이지를 이탈할 때 경고를 표시한다.

| 이탈 경로 | 구현 방법 | 표시 내용 |
|---------|---------|---------|
| 브라우저 탭 닫기 / 새로고침 / 외부 URL 이동 | `window.addEventListener('beforeunload', handler)` — 편집 dirty 상태일 때만 활성화 | 브라우저 기본 다이얼로그 ("변경사항이 저장되지 않을 수 있습니다.") |
| Next.js 내부 라우팅 (Sidebar 메뉴, 뒤로가기) | `useRouter` + `beforePopState` 또는 `useBlocker` (Next.js 15+ experimental) | shadcn/ui `<AlertDialog>`: "저장하지 않은 변경사항이 있습니다. 이 페이지를 떠나면 편집 내용이 소실됩니다." [계속 편집하기 (secondary)] [페이지 떠나기 (destructive)] |

> **dirty 상태 기준**: MDX Editor 초기 로딩 값(`body`)과 현재 에디터 값이 다른 경우. 저장 성공 후 즉시 dirty 상태 초기화.

## 8. 데이터 요구사항

### 입력 데이터 (UC-07·08)

| 필드 | 타입 | 필수 | 검증 규칙 |
|------|------|------|---------|
| `topic` | string | ✅ | 1자 이상, 300자 이내 |
| `keywords` | string[] | ❌ | 최대 5개, 각 50자 이내 |
| `direction` | string | ❌ | 200자 이내 |
| `guidelineId` | string \| null | ❌ | 유효한 지침 ID 또는 null |

### API 엔드포인트

| 메서드 | 엔드포인트 | 용도 |
|--------|-----------|------|
| `GET` | `/api/guidelines` | 지침 목록 조회 (드롭다운용) |
| `POST` | `/api/generate/stream` | AI 스트리밍 생성 요청 |
| `GET` | `/api/history/:id` | 생성 결과 조회 (에디터용) |

### 출력 데이터 (UC-09)

| 필드 | 설명 |
|------|------|
| `body` | AI 생성 마크다운 본문 |
| `topic` | 생성 시 입력한 주제 |
| `keywords` | 생성 시 입력한 키워드 배열 |
| `guideline_title` | 사용된 지침명 (삭제 시 "삭제된 지침") |
| `created_at` | 생성 일시 |
