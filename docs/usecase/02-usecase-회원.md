# UC-02~09 회원 (인증 · 계정 관리)

> **구현 상세(API 코드·함정·훅 레퍼런스)**: [`docs/tech/clerk.md`](../tech/clerk.md) 참조

## 1. 개요

| UC | 기능명 | 한 줄 설명 | 행위자 |
|----|--------|---------|--------|
| UC-02 | 회원가입 | 이메일+비밀번호로 계정을 생성하고 이메일 인증을 완료한다 | Visitor |
| UC-03 | 로그인 | 이메일+비밀번호로 인증하여 대시보드에 진입한다 | Visitor |
| UC-04 | 비밀번호 찾기 | 이메일 OTP를 받아 비밀번호를 재설정한다 | Visitor |
| UC-05 | 로그아웃 | 현재 세션을 종료하고 랜딩 페이지로 이동한다 | User |
| UC-06 | 프로필 수정 | 아바타·이름/성을 변경한다 | User |
| UC-07 | 비밀번호 변경 | 현재 비밀번호를 확인하고 새 비밀번호로 변경한다 | User |
| UC-08 | 세션 관리 | 활성 세션 목록을 조회하고 원격 종료한다 | User |
| UC-09 | 계정 삭제 | 계정과 모든 데이터를 영구 삭제한다 | User |

**구현 기반**: Clerk `@clerk/nextjs` v7+ (Core 3) 커스텀 플로우  
**인증 방법**: 이메일 + 비밀번호 (MVP 범위, 소셜 로그인 미지원)  
**users 테이블 동기화**: 회원가입 완료 후 Clerk Webhook(`user.created`) → 서버가 `users` 테이블에 자동 INSERT (클라이언트 별도 호출 불필요)

## 3. 정상 흐름

### UC-02 — 회원가입

| 단계 | 주체 | 내용 |
|------|------|------|
| 1 | Visitor | `/sign-up` 접근 또는 랜딩 "회원가입" CTA 클릭 |
| 2 | 시스템 | 이메일·비밀번호·비밀번호 확인 입력 폼 렌더링 |
| 3 | Visitor | 이메일, 비밀번호(8자 이상), 비밀번호 확인 입력 후 "회원가입" 클릭 |
| 4 | 시스템 | 클라이언트 유효성 검사. 통과 시 Clerk에 계정 생성 요청 |
| 5 | 시스템 | 가입 이메일로 6자리 OTP 발송. 인증 코드 입력 폼으로 전환 |
| 6 | Visitor | 이메일로 받은 OTP 6자리 입력 |
| 7 | 시스템 | OTP 검증 성공 → 세션 생성 → `/dashboard` 이동 |
| 8 | 시스템 | Clerk가 비동기로 `user.created` Webhook 발송 → `users` 테이블 INSERT |

### UC-03 — 로그인

| 단계 | 주체 | 내용 |
|------|------|------|
| 1 | Visitor | `/sign-in` 접근 (URL에 `redirect` 파라미터 포함 가능) |
| 2 | 시스템 | 이메일·비밀번호 입력 폼 렌더링 |
| 3 | Visitor | 이메일·비밀번호 입력 후 "로그인" 클릭 |
| 4 | 시스템 | Clerk 인증 요청. 성공 시 JWT 세션 쿠키 발급 |
| 5 | 시스템 | `redirect` 파라미터 경로 또는 `/dashboard`로 이동 |

### UC-04 — 비밀번호 찾기

| 단계 | 주체 | 내용 |
|------|------|------|
| 1 | Visitor | 로그인 폼의 "비밀번호를 잊으셨나요?" 클릭 → 비밀번호 재설정 폼으로 전환 |
| 2 | Visitor | 가입 이메일 입력 후 "인증 코드 발송" 클릭 |
| 3 | 시스템 | 해당 이메일로 OTP 발송. OTP + 새 비밀번호 입력 폼 표시 |
| 4 | Visitor | 이메일로 받은 OTP 및 새 비밀번호 입력 |
| 5 | 시스템 | OTP 검증 → 새 비밀번호 설정 완료 → "변경되었습니다." 안내 → 로그인 폼으로 전환 |

### UC-05 — 로그아웃

| 단계 | 주체 | 내용 |
|------|------|------|
| 1 | User | 헤더 아바타 드롭다운 → "로그아웃" 클릭 |
| 2 | 시스템 | 세션 종료. JWT 쿠키 삭제 → `/`(랜딩)으로 이동 |

### UC-06 — 프로필 수정

| 단계 | 주체 | 내용 |
|------|------|------|
| 1 | User | 아바타 드롭다운 → "계정 관리" → "프로필 수정" 탭 |
| 2 | User | 아바타 클릭 → 이미지 파일 선택 (PNG/JPG/WebP, 최대 2MB) |
| 3 | 시스템 | 선택 즉시 미리보기 표시 → Clerk에 업로드 → 성공 시 반영 |
| 4 | User | 성·이름 입력 후 "저장" 클릭 (변경사항 있을 때만 활성화) |
| 5 | 시스템 | Clerk에 이름 업데이트 → "저장됨" 피드백 표시 |

### UC-07 — 비밀번호 변경

| 단계 | 주체 | 내용 |
|------|------|------|
| 1 | User | "계정 관리" 모달 → "프로필 수정" 탭 → 비밀번호 변경 섹션 |
| 2 | User | 현재 비밀번호·새 비밀번호·새 비밀번호 확인 입력 후 "비밀번호 변경" 클릭 |
| 3 | 시스템 | 확인 패널 표시: "변경 후 자동 로그아웃됩니다." + 변경/취소 버튼 |
| 4 | User | "변경" 클릭 |
| 5 | 시스템 | 현재 비밀번호 검증 → 새 비밀번호 설정 → 세션 종료 → `/`로 이동 |

### UC-08 — 세션 관리

| 단계 | 주체 | 내용 |
|------|------|------|
| 1 | User | "계정 관리" 모달 → "계정 정보" 탭 |
| 2 | 시스템 | 활성 세션 목록 표시: 브라우저·OS·IP, 현재 세션 강조 |
| 3 | User | 다른 기기의 세션 "종료" 버튼 클릭 |
| 4 | 시스템 | 해당 세션 원격 종료. 목록에서 제거 |

### UC-09 — 계정 삭제

| 단계 | 주체 | 내용 |
|------|------|------|
| 1 | User | "계정 관리" 모달 → "계정 정보" 탭 → 계정 삭제 섹션 |
| 2 | 시스템 | 경고 메시지: "모든 데이터가 영구 삭제되며 복구할 수 없습니다." |
| 3 | User | 확인 입력란에 "계정삭제" 입력 (삭제 버튼 활성화) |
| 4 | User | "계정 영구 삭제" 클릭 |
| 5 | 시스템 | 계정 및 모든 데이터 삭제 → 로그아웃 → `/`로 이동 |

## 7. UI/UX 고려사항

### 인증 페이지 공통

- **레이아웃**: 화면 중앙 정렬 카드(`max-w-md`). PublicHeader·Footer 미표시.
- **이미 로그인 상태**: 페이지 진입 즉시 `/dashboard` 리다이렉트 (영어 오류 메시지 미노출).
- **버튼 로딩 상태**: 요청 중 버튼 비활성화 + 스피너 표시.
- **에러 위치**: 필드 하단 인라인 에러 또는 폼 상단 전역 에러.
- **회원가입 ↔ 로그인 전환**: 각 페이지 하단 상호 링크.
- **"비밀번호를 잊으셨나요?"**: 로그인 폼 비밀번호 필드 하단. Muted 색상.

### 계정 관리 모달

- shadcn `Dialog` 사용. 권장 너비: `sm:max-w-2xl`.
- **좌우 분할**: 좌측 사이드바(탭 메뉴) + 우측 콘텐츠 영역.
- **탭**: "프로필 수정" (아바타·이름·비밀번호 변경) / "계정 정보" (기본 정보·현재 기기·세션·계정 삭제).
- **아바타**: 업로드 중 카메라 아이콘 자리에 스피너 표시. 업로드 즉시 미리보기.
- **비밀번호 변경 확인 패널**: 변경 전 로그아웃 경고 명시. 변경/취소 버튼.
- **계정 삭제**: 입력란 미일치 시 삭제 버튼 비활성화. 경고 배너 표시.

### 헤더 아바타 드롭다운

- 커스텀 아바타 없으면 이름·이메일 이니셜 fallback 표시.
- 드롭다운 항목: 이름 + 이메일 표시(헤더) → 계정 관리 → 구분선 → 로그아웃.

## 10. 완료 조건

### 인증

- [ ] 회원가입: 이메일+비밀번호 입력 → OTP 인증 → 대시보드 이동
- [ ] 이미 가입된 이메일: 한글 에러 메시지 표시
- [ ] 로그인: 이메일+비밀번호 → 대시보드 이동
- [ ] 이미 로그인 상태로 `/sign-in`·`/sign-up` 접근: 대시보드 자동 리다이렉트
- [ ] 비밀번호 찾기: 이메일 OTP → 새 비밀번호 설정 → 완료 안내
- [ ] 로그아웃: 세션 종료 → 랜딩(`/`)으로 이동
- [ ] 모든 Clerk 에러: 영어 원문 미노출, 한글 메시지 표시

### 계정 관리

- [ ] 헤더: 로그인 시 아바타(커스텀) 또는 이니셜 표시
- [ ] 드롭다운: 이름·이메일·계정 관리·로그아웃 항목
- [ ] 계정 관리 모달: 좌우 분할, 탭 전환
- [ ] 프로필 수정 탭: 아바타 업로드·이름 수정 저장
- [ ] 비밀번호 변경: 현재 비밀번호 확인 → 확인 패널 → 변경 성공 시 로그아웃
- [ ] 계정 정보 탭: 기본 정보(이메일·가입일·최근 로그인), 현재 접속 기기(IP·OS·브라우저)
- [ ] 세션 관리: 활성 세션 목록(브라우저·OS·IP), 현재 세션 강조, 다른 세션 원격 종료
