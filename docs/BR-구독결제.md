# [BR-02] 구독 및 결제 정책

이 문서는 **IndiePost AI**의 조직 단위 구독 및 토스페이먼츠 연동 정책을 정의합니다.

## 1. 기본 원칙

- **조직 단위 구독:** 결제와 사용량 한도(Quota)는 개인이 아닌 **조직(Organization)** 단위로 관리됩니다.
- **기존 데이터 보존:** 모든 기존 유저는 '개인 조직(Personal Org)'으로 백필되어 기존 생성 이력을 그대로 유지합니다.

## 2. 요금제 정책 (Plan)

| 항목          | Free (무료)                            | Pro (유료)               |
| :------------ | :------------------------------------- | :----------------------- |
| **가격**      | 0원                                    | 29,900원 (월, VAT 포함)  |
| **생성 한도** | **월 10회** (초기 3회 아님, 월간 갱신) | **월 200회**             |
| **사용 모델** | Gemini 1.5 Flash                       | Gemini 1.5 Pro (고품질)  |
| **조직 관리** | 멤버 초대 불가 (1인 전용)              | 멤버 최대 3명 초대 가능  |
| **AI Agent**  | 사용 불가                              | 최대 3개 에이전트 활성화 |
| **번역 기능** | 월 5회                                 | 월 100회                 |

## 3. 수정된 사용자 플로우

### 3.1 글 작성 검증 로직

1.  **진입:** 사용자가 `/generate` 페이지 진입 시 상단에 `현재 조직의 잔여 횟수 / 전체 한도`를 표시합니다.
2.  **차단:** 잔여 횟수가 0인 경우 '생성 버튼'을 비활성화하고 "이번 달 한도를 모두 사용했습니다. 플랜을 업그레이드하세요."라는 메시지와 함께 `/billing` 이동 링크를 노출합니다.
3.  **서버 검증 (Hono 미들웨어):**
    - `POST /api/generate/stream` 호출 시 `withOrgQuota` 미들웨어가 DB의 `usage_quotas`를 확인합니다.
    - 한도 초과 시 `402 Payment Required` 에러를 반환합니다.
4.  **차감:** AI 생성이 성공적으로 시작되면 즉시 `usage_quotas.generations_used`를 +1 증가시킵니다.

### 3.2 결제 및 해지 로직

- **정기 결제:** 토스페이먼츠의 **빌링키(Billing Key)** 방식을 사용합니다. 최초 1회 카드 등록 후 매달 자동 결제됩니다.
- **구독 해지:** 사용자가 해지를 신청하면 즉시 종료되지 않고, **'해지 예약'** 상태가 됩니다. 이번 달 결제 주기가 끝날 때까지(`current_period_end`) Pro 기능을 계속 사용할 수 있습니다.
- **해지 취소:** 결제 예정일 전이라면 언제든 '해지 예약'을 취소하고 다시 구독 상태로 복구할 수 있습니다.
- **빌링키 삭제:** 구독이 최종적으로 종료(결제 주기 만료)되는 시점에 토스 서버에서 빌링키를 삭제합니다.

## 4. 백엔드 및 자동화 설계 (Vercel Cron)

### 4.1 데이터베이스 변경 사항

- `subscriptions`: 조직의 구독 상태, 빌링키, 다음 결제일 저장.
- `payments`: 개별 결제 성공/실패 기록 (영수증).
- `usage_quotas`: 조직별 월간 사용량 카운터.

## 4. 결제 및 자동화 로직 (Upstash QStash 기반)

### 4.1 자동 결제 시스템

- **트리거:** Upstash QStash가 **매일 02:00 (KST)**에 /api/cron/billing/tick 엔드포인트를 호출합니다.
- **신뢰성(Retry):** 결제 API 호출 중 일시적인 네트워크 오류가 발생할 경우, QStash의 **자동 재시도 로직**에 의해 최대 3회까지 재시도합니다.
- **보안:** 모든 결제 API는 QStash가 발급한 **암호화 서명(Signature)**을 검증하여, 허가되지 않은 외부 호출을 원천 차단합니다.
    

### 4.2 구독 해지 및 빌링키 관리

- **해지 예약:** 해지 시 즉시 종료되지 않고 차기 결제일까지 Pro 상태를 유지합니다.
- **빌링키 파기:** 구독 기간이 완전히 만료되는 시점에 토스페이먼츠 빌링키를 삭제하며, 재구독 시 신규 등록이 필요합니다.

## 5. UI/UX 디자인 요구사항

- **사이드바 하단 위젯:**
  - 현재 요금제 이름(Free/Pro) 표시.
  - 사용량 Progress Bar (예: 8/10).
  - 업그레이드 유도 버튼 (Free일 때만).
- **구독 관리 페이지 (`/billing`):**
  - **카드 섹션:** 현재 구독 중인 플랜 정보, 다음 결제 금액 및 날짜.
  - **결제 수단:** 등록된 카드 정보(예: 현대카드 4\*\*\*) 표시 및 변경 버튼.
  - **결제 내역:** 날짜, 금액, 상태, 영수증 보기 버튼이 포함된 테이블.
