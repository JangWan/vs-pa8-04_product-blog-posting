# PRD — IndiePost AI
> 인디해커를 위한 제품 블로그 콘텐츠 AI 자동 작성 서비스  
> 작성일: 2026-05-15 | 버전: v1.1 (2026-05-18 Phase 3 정합화)

---

## 1. 제품 상세 설명

### 핵심 가치 (한 문장)
1인 인디해커가 제품 주제만 입력하면, AI가 일관된 브랜드 톤으로 SEO 최적화된 블로그 글을 자동으로 작성해준다.

### 제품 개요
| 항목 | 내용 |
|------|------|
| 서비스명 | IndiePost AI |
| 카테고리 | AI SaaS / 콘텐츠 생성 |
| 타겟 플랫폼 | Web (반응형) |
| 데이터 저장 방식 | Database (서버 DB) |
| 개발 방향 | MVP → 애자일 → Build in Public |

### 문제 정의
1인 인디해커는 제품 개발·운영·마케팅을 혼자 담당한다. 블로그는 가장 효과적인 유기적 마케팅 채널이지만, 글을 쓰는 데 걸리는 시간과 SEO 지식 부족이 발목을 잡는다. 결과적으로 블로그가 방치되고 제품 노출 기회를 잃는다.

### 해결 방향
- **주제만 입력** → AI가 초안을 즉시 생성 (시간 절약)
- **지침 관리** → AI가 항상 같은 브랜드 톤으로 글을 쓰도록 보장 (일관성)
- **SEO 최적화 프롬프트** → 검색 유입을 고려한 구조로 자동 작성 (노출 증가)
- **서비스 안정성 (Phase 3)** → 메시지 큐 기반 자동화로 정기결제·자동 글 생성에서 일시적 오류를 자동 재시도하여 결제 성공률·작업 신뢰성 보장

## 2. 유사 서비스 분석 및 차별화 근거

| 서비스 | 대상 | 강점 | 약점 | 차별화 포인트 |
|--------|------|------|------|--------------|
| **Copy.ai** | 마케터·기업 | 다양한 템플릿, 팀 협업 | 인디해커 특화 없음, 구독료 비쌈 | IndiePost: 인디해커 특화 + 낮은 진입 비용 |
| **Jasper AI** | 기업 마케팅팀 | 고품질 장문 생성, 브랜드 보이스 | 복잡한 UX, 고가 요금제 | IndiePost: 단순 UX, 지침 기반 일관성 |
| **Hashnode AI** | 개발자 블로거 | 개발자 친화, 블로그 플랫폼 내장 | SEO 최적화 취약, 지침 관리 없음 | IndiePost: SEO 프롬프트 내장 + 지침 관리 |

**핵심 차별화**: 인디해커의 "제품 이야기"에 특화된 AI 지침 관리 + SEO 최적화 자동화. 기존 도구는 일반 마케팅 콘텐츠에 최적화되어 있어, 개인 브랜드 톤을 일관되게 유지하는 기능이 부족하다.

## 3. 핵심 기능 정의 및 명세 (Must-have)

### F1. 주제 입력 → 콘텐츠 자동 작성
| 항목 | 내용 |
|------|------|
| 설명 | 블로그 주제(제목·키워드·방향)를 입력하면 AI가 완성된 글 초안을 생성 |
| 입력 | 주제명, 키워드(선택), 글 방향(선택) |
| 출력 | 마크다운 형식의 블로그 초안 |
| 제약 | 생성된 초안은 에디터에서 직접 편집 가능해야 함 |

### F2. AI 일관성 지침(지시서) 관리
| 항목 | 내용 |
|------|------|
| 설명 | 브랜드 톤·문체·금지 표현·글쓰기 규칙을 지침으로 등록하면 모든 생성에 자동 적용 |
| 입력 | 텍스트 형식의 지침 내용 |
| 출력 | 등록된 지침이 반영된 생성 결과 |
| 제약 | 지침은 생성 시 시스템 프롬프트에 자동 주입됨 |

### F3. SEO 최적화 시스템 프롬프트
| 항목 | 내용 |
|------|------|
| 설명 | 검색엔진 최적화 구조(제목 태그, 메타 설명, 소제목 계층, 키워드 밀도)를 AI가 자동 반영 |
| 입력 | 타겟 키워드 (선택) |
| 출력 | SEO 구조가 내장된 블로그 초안 |
| 제약 | 별도 SEO 설정 없이 기본 적용됨 |

## 5. 사용자 페르소나 및 시나리오

### 페르소나
| 항목 | 내용 |
|------|------|
| 이름 | 김민준 (가상) |
| 나이 | 28~35세 |
| 직업 | 1인 인디해커 / 사이드 프로젝트 운영자 |
| 상황 | 낮에는 본업, 저녁·주말에 사이드 프로젝트 개발·운영 |
| 간절한 문제 | "블로그는 써야 하는데 시간이 없고, 매번 톤이 달라 브랜드 이미지가 흔들림. SEO도 잘 모름" |

### 핵심 시나리오 (Happy Path)
1. 로그인 후 지침 관리 페이지에서 브랜드 톤·문체 지침을 1회 등록
2. 콘텐츠 생성 페이지에서 주제("Next.js로 SaaS 만든 후기") 입력
3. AI가 등록된 지침 + SEO 프롬프트를 적용하여 초안 생성 (30초 이내)
4. 에디터에서 초안 검토·수정
5. 완성된 글을 복사하여 블로그 플랫폼에 게시
